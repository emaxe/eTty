# Спецификация: Git Panel

## Контекст

eTty — терминальное Electron-приложение с git-интеграцией. Панель прошла две итерации:

- **v1** (этот документ ранее описывал только её): полноэкранный оверлей с одноколоночным списком файлов, где diff разворачивался аккордеоном под строкой; коммит всегда захватывал все изменения (`git commit -am`), staging был недоступен.
- **v2** (текущая): двухпанельный master/detail оверлей — слева сгруппированный по статусу список файлов с фильтром, справа unified diff с номерами строк, подсветкой синтаксиса и посимвольным word-diff. Добавлены staging (index), действия над отдельным файлом, хоткей открытия, автообновление без потери состояния.

Git-контекст определяется по `rootPath` активной вкладки — simple-git ищет репозиторий вверх по дереву от этой директории.

## Требования

**Статус-бар:**
- REQ-1: В нижней части окна постоянно отображается полоса высотой 22px с кнопкой `± +{additions} -{deletions}`.
- REQ-2: Кнопка обновляется каждые 5 секунд (polling, `GitStatusService`) на основе `rootPath` активной вкладки.
- REQ-3: При смене активной вкладки — немедленное внеплановое обновление кнопки.
- REQ-4: Если `rootPath` активной вкладки не является git-репозиторием — кнопка скрыта.

**Git-панель — открытие/закрытие:**
- REQ-5: Клик по кнопке статус-бара, либо хоткей `Cmd/Ctrl+Shift+G`, открывает/закрывает git-панель (полноэкранный оверлей).
- REQ-6: Панель закрывается кнопкой `✕`, клавишей `Esc` или повторным `Cmd/Ctrl+Shift+G`.
- REQ-7: При открытии панель немедленно запрашивает актуальный статус и список веток; фокус ставится в поле фильтра.
- REQ-8: Пока панель открыта, она слушает событие `git.status-updated` (эмитится `GitStatusService` раз в 5 сек и при сохранении файла в редакторе) и молча обновляет данные, сохраняя выделенный файл, скролл обеих панелей и текст сообщения коммита.

**Git-панель — шапка и ветки:**
- REQ-9: Кнопка ветки в шапке открывает поповер с полем поиска и списком локальных веток.
- REQ-10: Клик по ветке в поповере (или Enter при точном совпадении) выполняет `git checkout <branch>`.
- REQ-11: Если введённый текст не совпадает ни с одной веткой — пункт «+ Create branch "…"» создаёт и переключается на новую ветку.
- REQ-12: Иконка корзины у ветки (кроме текущей) удаляет её через `ConfirmDialog`; заблокировано, если ветка одна или называется `main`/`master`.
- REQ-13: В шапке также отображаются `↑ahead`/`↓behind` относительно upstream и суммарные `+N`/`-N` по всем изменениям.
- REQ-14: Ошибки операций отображаются в тост-полосе (`.git-toast`) на 4 секунды, успех — на 2 секунды (зелёным).

**Git-панель — список файлов (левая панель):**
- REQ-15: Файлы сгруппированы по `Staged Changes` / `Changes` / `Untracked` / `Ignored`, каждая группа сворачивается, показывает счётчик и (кроме `Ignored`) кнопку массового действия (`Stage all` / `Unstage all`).
- REQ-16: Поле фильтра (debounce) сужает список по подстроке пути внутри всех групп.
- REQ-17: Строка файла показывает чекбокс (stage/unstage), цветной бейдж статуса (`M`/`A`/`D`/`R`/`U`/`I`), путь и `+N`/`-N`.
- REQ-18: Клавиатура: `↑`/`↓` — навигация по видимым файлам, `Enter` — открыть в редакторе, `Space` — stage/unstage, `/` — фокус в фильтр (когда фокус не в текстовом поле).
- REQ-19: ПКМ по строке открывает контекстное меню: Open in Editor / Copy Path / Stage или Unstage / Discard Changes (последние два скрыты для группы `Ignored`).

**Git-панель — diff (правая панель):**
- REQ-20: Diff рендерится как unified с отдельными колонками номеров старой/новой строки, подсветкой синтаксиса (через `@lezer/highlight` classHighlighter, без монтирования CodeMirror) и посимвольным выделением изменённого фрагмента внутри пар `-`/`+` строк.
- REQ-21: Шапка diff-панели показывает путь, бейдж статуса, `+N`/`-N` и кнопки `Open` / `Stage` или `Unstage` / `Discard` (последние скрыты для игнорируемых файлов).
- REQ-22: Отдельно обрабатываются: бинарный файл («Binary file — diff not shown»), отсутствие изменений, игнорируемый файл (без запроса к IPC), и слишком большой diff (кнопка «Show anyway» вместо автоматического рендера).
- REQ-23: При выборе нового файла показывается скелетон-заглушка; при фоновом обновлении (тот же файл, тот же выбор) скелетон не показывается — контент подменяется без мигания.

**Git-панель — staging, коммит, пуш, discard:**
- REQ-24: Stage/unstage доступны через чекбокс строки, контекстное меню, кнопку в шапке diff-панели и кнопку массового действия группы.
- REQ-25: Блок коммита содержит текстовое поле сообщения (`Cmd/Ctrl+Enter` — коммит), кнопки `Commit`, `Push`, `⋯` (Discard All Changes через `ConfirmDialog`).
- REQ-26: `Commit` коммитит только застейдженные файлы, если индекс не пуст; если индекс пуст — коммитит все tracked-изменения (`git commit -a`), сохраняя однокликовый сценарий для тех, кто не пользуется staging.
- REQ-27: `Push` во время выполнения показывает `…` вместо текста и блокирует блок действий.
- REQ-28: Discard одного файла и Discard All подтверждаются через `ConfirmDialog` (не инлайн-текстом).

## Ограничения

- Staging по hunks/отдельным строкам — **не входит в скоуп** (только весь файл целиком).
- Работа с remote (fetch, pull, merge, rebase) — **не входит в скоуп** (только push).
- Удаление remote-веток — **не входит в скоуп** (только локальные).
- Разрешение merge-конфликтов — вне скоупа; конфликтующие файлы показываются с бейджем `U`, но без merge-инструментов.
- Работа с несколькими репозиториями одновременно — **не входит в скоуп**.
- Визуализация git log / history — **не входит в скоуп**.

## Кодстайл и конвенции

- Vanilla JavaScript, ES6 модули — никаких фреймворков.
- Компоненты в `src/renderer/features/git/`: `git-panel.js` (оркестратор), `git-file-list.js`, `git-diff-view.js`, `diff-parser.js`, `diff-highlighter.js`, `git-status.js`.
- DI через конструктор: `GitPanel({ overlayEl, eventBus, store, api, confirmDialog, onClose })`.
- CSS-переменные для всех цветов, включая токены подсветки синтаксиса diff (`--dt-keyword`, `--dt-string`, … — устанавливаются из `theme.editor` в том же подписчике `ui.theme`, что применяет остальные UI-переменные).
- IPC только через `IPC_CHANNELS` (`shared/ipc-channels.js`) и `ElectronApiAdapter`.
- Обработка ошибок: все git-операции — `try/catch` в `src/main/ipc-handlers/git-handlers.js`; IPC возвращает `{ ok: true }` или `{ error: string }`.
- Нет сторонних библиотек для рендера диффа/подсветки — собственный парсер unified diff и `@lezer/highlight` (уже прямая зависимость проекта, используется и в редакторе).

## Переиспользуемые решения

- `src/renderer/confirm-dialog.js` — модальное подтверждение для discard/удаления ветки.
- `src/renderer/components/base/button/button.js`, `components/base/context-menu/context-menu.js` — UI-kit кнопки и контекстное меню.
- `src/renderer/services/git-status-service.js` — источник события `git.status-updated`, драйвит автообновление панели.
- `src/renderer/editor-languages.js` — резолвинг грамматики CodeMirror по расширению файла, переиспользуется для подсветки diff.
- `src/renderer/index.js` — место инициализации `GitPanel`, подписка на `ui.gitPanelVisible`, хоткей `Cmd/Ctrl+Shift+G`, применение `--dt-*` при смене темы.

## Критерии приёмки

- [ ] Статус-бар виден внизу окна, кнопка обновляется при смене вкладки и раз в 5 сек.
- [ ] Кнопка скрывается если `rootPath` не является git-репозиторием.
- [ ] Клик по кнопке и `Cmd/Ctrl+Shift+G` открывают/закрывают панель; `Esc` закрывает.
- [ ] Файлы сгруппированы по Staged/Changes/Untracked/Ignored, счётчики и bulk-действия работают.
- [ ] Фильтр сужает список по подстроке пути; клавиатурная навигация работает.
- [ ] Stage/unstage работает через чекбокс, контекст-меню, кнопку и bulk-действие; отражается в `git status`.
- [ ] Diff показывает номера строк, подсветку синтаксиса и word-diff; бинарные/пустые/игнорируемые/слишком большие diff обрабатываются отдельными состояниями.
- [ ] `Commit` коммитит только staged при непустом индексе, иначе — все изменения; поле очищается после успеха.
- [ ] `Push` показывает индикатор выполнения.
- [ ] Discard (файл и все) подтверждается через `ConfirmDialog`.
- [ ] Переключение веток, создание и удаление через поповер работают; `main`/`master` и последняя ветка защищены.
- [ ] Автообновление (5 сек / после сохранения файла) не сбрасывает выделение, скролл и текст коммита.
- [ ] UI соответствует теме приложения во всех встроенных темах (включая цвета diff и подсветку синтаксиса).
