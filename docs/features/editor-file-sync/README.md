# Фича: Синхронизация открытого файла с диском

**Slug:** editor-file-sync
**Jira:** не привязана
**Git-ветка:** не требуется
**Базовая ветка для merge:** не применимо
**Дата начала:** 2026-05-06
**Статус:** Done

## Краткое описание

Доработка панели редактора для отслеживания внешних изменений файлов на диске (сторонние процессы, git, другие редакторы). Автоматическая синхронизация при повторном открытии, ручная синхронизация по кнопке, диалог разрешения конфликтов при несохранённых изменениях пользователя.
