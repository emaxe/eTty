# Стартовый промпт для реализации фичи «Синхронизация открытого файла с диском»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Синхронизация открытого файла с диском** по подготовленной документации.

## Документация

- Спецификация: `docs/features/editor-file-sync/spec.md` — прочитай перед началом
- План: `docs/features/editor-file-sync/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/editor-file-sync/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай `spec.md`, `plan.md` и `checklist.md` целиком.
2. Отдельную ветку не создавай (см. `README.md`).
3. Отметь в `checklist.md` пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в `plan.md`:
   - Блоки 1 и 2 (IPC + UI) — параллельно в одной сессии
   - Блок 3 (EditorPanel) — строго после завершения Блоков 1 и 2, последовательно задача за задачей
5. После **каждой** задачи: ревью по `plan.md` и `spec.md`; убедись, что нет конфликта с параллельными задачами.
6. После выполнения задачи — отметь её в `checklist.md` (`[x]`).
7. Запусти указанную для задачи проверку.
8. Коммить после каждого логического блока задач.
9. По завершении — отметь «Финализация» в `checklist.md` и обнови статус в `README.md` на `Done`.
10. Если что-то непонятно — спроси, не додумывай.
