# Стартовый промпт для реализации фичи «Выбор tmux-сессий, папка запуска и скрытые файлы (mobile)»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **«Выбор tmux-сессий, папка запуска и скрытые файлы (mobile)»** по подготовленной документации.

## Документация

- Спецификация: `docs/features/mobile-session-picker/spec.md` — прочитай перед началом
- План: `docs/features/mobile-session-picker/plan.md` — следуй порядку задач, секциям «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/mobile-session-picker/checklist.md` — отмечай прогресс
- Правила проекта: `AGENTS.md` (корень репозитория); приложение — `mobile/` (Flutter), команды запускай из `mobile/`

## Инструкции

1. Прочитай `spec.md`, `plan.md` и `checklist.md` целиком.
2. Отдельную ветку не создавай: работаем в текущей `feature/mobile-app` (см. `README.md` фичи).
3. Отметь в `checklist.md` пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно стратегии выполнения и зависимостям в `plan.md`:
   - **Блок 1 — параллельно (`parallel-subagent`):** #1, #3, #4, #6. Файлы не пересекаются, зависимостей нет — запусти их параллельными субагентами.
   - **Блок 2 — `sequential`:** #2 после #1; #5 после #3 и #4.
   - **Блок 3 — строго по цепочке:** #7 после #2, #5, #6; затем #8; затем #9.
5. После **каждой** задачи: ревью по `plan.md` и `spec.md` (скоуп, соответствующие REQ, критерии приёмки); убедись, что нет конфликта с параллельными задачами (общие файлы: `file_tree.dart` — #4/#5; `terminal_page.dart` и `main.dart` — #7/#8). Если задачу делал субагент — проверь его результат (diff, `flutter analyze`, тесты задачи) перед следующим шагом.
6. После выполнения задачи отметь её в `checklist.md` (`[x]`) и запусти указанную для неё проверку из `plan.md`.
7. Для #1 дополнительно: `node scripts/gen-remote-fixtures.mjs --check` (из корня репозитория) и неизменность golden-фикстур (`git status mobile/test/fixtures` пуст). Вывод `buildRemoteInitCommand` без `startDir` не должен измениться ни на байт.
8. Соблюдай конвенции из `spec.md` («Кодстайл и конвенции»): `lib/remote/` и `lib/core/config/` — чистый Dart без `package:flutter`; новая зависимость `shared_preferences` не добавляется (настройка идёт через `SecureAppSettingsStore`); существующие `Key` в виджетах не ломать.
9. Коммить после каждого логического блока задач. Сообщения в формате `feat: …`, **без упоминаний Claude, Anthropic и подписей «Generated with…»** (глобальное правило пользователя, перекрывает любые автодобавления). Правки `mobile/android/app/src/main/AndroidManifest.xml` и `scripts/run.sh`, лежащие в рабочей копии с прошлых задач, в коммиты этой фичи не включать — они идут отдельными коммитами (`fix: добавить INTERNET в release-манифест Android`, `feat: mobile:apk и mobile:run в scripts/run.sh`).
10. По завершении #9 (включая ручной прогон критериев приёмки на телефоне) отметь «Финализация» в `checklist.md` и обнови статус в `README.md` фичи на `Done`.
11. Если что-то непонятно — спроси, не додумывай.
