# Стартовый промпт для реализации фичи «Рекурсивное отслеживание файловой системы»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Рекурсивное отслеживание файловой системы** по подготовленной документации.

## Документация

- Спецификация: `docs/features/fs-watch-recursive/spec.md` — прочитай перед началом
- План: `docs/features/fs-watch-recursive/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага"
- Чеклист: `docs/features/fs-watch-recursive/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай spec.md, plan.md и checklist.md целиком.
2. Создай/переключись на ветку `feature/fs-watch-recursive` (`git checkout -b feature/fs-watch-recursive` или `git checkout feature/fs-watch-recursive` если уже создана).
3. Отметь в checklist.md пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в plan.md:
   - **sequential** (1-9) — строго по порядку
   - **parallel-same** (10, 11) — можно выполнять параллельно с другими задачами после зависимостей
5. После **каждой** задачи: ревью по plan.md и spec.md; убедись, что нет конфликта с параллельными задачами (особенно watchers в file-manager.js).
6. После выполнения задачи — отметь её в checklist.md (`[x]`).
7. Запусти указанную для задачи проверку (см. колонку «Проверка» в plan.md).
8. Коммить после каждого логического блока задач (или по правилам команды).
9. По завершении — отметь «Финализация» в checklist.md и обнови статус в README.md на `Done`.
10. Если что-то непонятно — спроси, не додумывай.

## Особенности этой фичи

- **Ключевой файл:** `src/main/file-manager.js` — там уже есть базовый `watchDirectory`, нужно расширить
- **UI файл:** `src/renderer/file-tree.js` — управление expand/collapse и watchers
- **Лимит:** максимум 100 watchers, при превышении — warning и fallback на корневую директорию
- **Cleanup:** watchers должны удаляться при смене вкладки, смене root, collapse папки
