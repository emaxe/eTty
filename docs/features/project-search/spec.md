# Спецификация: Поиск по проекту

## Контекст

В eTty отсутствует возможность быстрого поиска файлов и содержимого внутри текущего проекта. Пользователи вынуждены использовать терминальные команды (`grep`, `find`, `fzf`) или внешние редакторы. Встроенный поисковый диалог ускорит навигацию по коду и сделает eTty более самодостаточным.

Фича реализуется как модальное диалоговое окно в renderer-процессе с поисковой логикой в main-процессе (через IPC). Диалог следует существующим паттернам оверлеев (`SettingsPage`, `GitPanel`).

## Требования

### Поисковые возможности

**REQ-1.** Поиск выполняется **только внутри корневой папки текущей вкладки** (cwd терминала / root file tree).

**REQ-2.** Поиск ведётся одновременно по **именам файлов** и по **содержимому файлов**.
- Результаты по именам файлов отображаются **первыми** (выше результатов по содержимому).
- Имя файла считается совпадающим, если содержит поисковую подстроку (case-insensitive по умолчанию).
- Содержимое файла считается совпадающим, если хотя бы одна строка содержит подстроку.

**REQ-3.** Параметры поиска (настройки в диалоге):
- **Case sensitive** — переключатель (по умолчанию `off`).
- **Whole word** — переключатель (по умолчанию `off`).
- **Regex** — переключатель (по умолчанию `off`). При включении поисковая строка интерпретируется как регулярное выражение.
- **Include / exclude patterns** — текстовое поле с glob-паттернами через запятую (например, `*.js,*.ts`, `!node_modules,!*.log`). По умолчанию исключать: `node_modules,.git,dist,out,build`.

**REQ-4.** Производительность и ограничения:
- Поиск в main-процессе должен быть **отменяемым** (через AbortController или флаг).
- Максимальный размер файла для чтения содержимого: **1 МБ** (файлы больше — только по имени).
- Максимальное количество результатов по содержимому: **500 совпадений** (чтобы не перегружать UI).

### UI диалога поиска

**REQ-5.** Диалог открывается как **модальный оверлей** поверх всего окна (аналогично `settings-dialog-overlay`), с фиксированным затемнённым фоном (`rgba(0,0,0,0.5)`), `z-index: 600`.

**REQ-6.** Шапка диалога:
- Поле ввода поискового запроса (input, широкое, фокус при открытии).
- Панель переключателей параметров (case sensitive, whole word, regex, include/exclude).
- Кнопка закрытия (×).

**REQ-7.** Область результатов разделена на **две части**:
- **Верхняя часть** — список найденных файлов. Для каждого файла: иконка, имя файла, относительный путь. Файлы, найденные по имени, отображаются первыми и помечаются соответствующей меткой (например, текст "Имя файла" или мини-иконка).
- **Нижняя часть** — просмотр содержимого **выбранного** файла из верхнего списка. При выборе файла (клик) подсвечиваются строки с совпадениями.

**REQ-8.** Взаимодействие с результатами:
- **Клик** на файл в верхней части — выбирает файл и показывает его содержимое в нижней части.
- **Двойной клик** на файл — открывает файл в панели редактора (`eventBus.emit('filetree.openFile', path)`) и **закрывает** диалог поиска.
- **Enter** при фокусе в списке файлов — открывает выделенный файл в редакторе и закрывает диалог.
- Навигация стрелками ↑/↓ по списку файлов.

**REQ-9.** Пустые и загружающиеся состояния:
- При пустом запросе — показывать placeholder "Введите запрос для поиска".
- При вводе запроса — показывать индикатор загрузки (спиннер) до получения результатов.
- При отсутствии результатов — показывать "Ничего не найдено".

### Способы открытия диалога

**REQ-10.** Кнопка с иконкой лупы в панели навигации файлового дерева (`#sidebar-nav`), **прижата к правому краю** группы кнопок, рядом с `btn-refresh-tree` и `btn-toggle-hidden`.

**REQ-11.** Глобальное сочетание клавиш **Cmd+F** (macOS) / **Ctrl+F** (Windows/Linux). Перехватывается на уровне `document` в `index.js`, не срабатывает если фокус в CodeMirror (редактор обрабатывает свой поиск).

**REQ-12.** **Двойное нажатие Shift** (два последовательных нажатия Shift в течение 300 мс). Реализовать через таймер сброса.

### Закрытие диалога

**REQ-13.** Закрытие по:
- Клик на затемнённый фон (backdrop).
- Клавиша **Escape**.
- Кнопка × в шапке.
- Открытие файла по двойному клику / Enter.

## Ограничения

- Поиск не индексирует проект заранее — каждый запрос выполняет полный обход директорий. Для больших проектов (>100K файлов) это может быть медленно; acceptable для MVP.
- Не поддерживается fuzzy-поиск (типа fzf) в первой версии — только substring / regex.
- Не поддерживается поиск по бинарным файлам (картинки, архивы и т.д.).
- Просмотр содержимого в нижней части — read-only, без редактирования (для редактирования открывать в editor-panel).

## Макеты и референсы

> Не применимо — макетов Figma нет. За образец UI взяты существующие диалоги (`settings-dialog-overlay`, `git-overlay`).

## Кодстайл и конвенции

- Все новые компоненты — через **DI Container** (`core/container.js`), зависимости в constructor.
- Коммуникация между компонентами — через **EventBus** (`core/event-bus.js`).
- Shared state (видимость диалога) — через **StateStore** (`core/state-store.js`) или внутреннее состояние компонента (допустимо для транзиентного модала).
- Имена IPC-каналов — только в `shared/ipc-channels.js`, никаких строковых литералов.
- CSS-цвета — через CSS-переменные (`var(--bg)`, `var(--accent)` и т.д.), новые переменные добавлять в `styles.css :root` и `themes.js`.
- Нет прямых обращений к `window.electronAPI` — только через адаптер (`core/adapters/electron-api.js`).
- Каждый компонент с подписками имеет метод `destroy()`.
- Магические числа/интервалы — в `core/config/app-config.js`.

|---------------------|------|----------------------|
| SettingsPage (overlay pattern) | `src/renderer/settings-page.js` | Паттерн `show()` / `hide()` / `_buildDOM()` / `.hidden` класс / backdrop overlay |

| FileTree / sidebar nav | `src/renderer/file-tree.js`, `index.html` | Добавить кнопку в `#sidebar-nav` |
| Icons | `src/renderer/icons.js` | Добавить SVG-иконку лупы |
| IPC handlers | `src/main/ipc-handlers/fs-handlers.js` | Паттерн `register*Handlers(ipcMain, deps)` + `try/catch` + `{success, error}` |
| FileManager | `src/main/file-manager.js` | Паттерн `validatePath()`, обход директорий через `fs.readdir` |

| EventBus events | `src/renderer/index.js` | `bus.on('filetree.openFile', ...)` — использовать для открытия файла |

## Критерии приёмки

- [ ] Кнопка лупы видна в `#sidebar-nav`, корректно отображается во всех темах.
- [ ] Cmd+F / Ctrl+F открывает диалог, не конфликтует с CodeMirror поиском.
- [ ] Двойное нажатие Shift открывает диалог.
- [ ] Поиск по имени файла работает (подстрока, case-insensitive).
- [ ] Поиск по содержимому файла работает (совпадения в строках).
- [ ] Результаты по имени отображаются выше результатов по содержимому.
- [ ] Выбор файла (клик) показывает содержимое с подсветкой совпадений.
- [ ] Двойной клик открывает файл в editor-panel и закрывает диалог.
- [ ] Escape / клик на backdrop / кнопка × закрывают диалог.
- [ ] Параметры (case sensitive, whole word, regex, include/exclude) влияют на результаты.
- [ ] Поиск отменяется при смене запроса (не гоняются старые результаты).
- [ ] `npm run build` проходит без ошибок.
- [ ] Нет регрессий: терминал, вкладки, дерево файлов, редактор, git-панель работают как раньше.
