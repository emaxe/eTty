# Стартовый промпт для реализации фичи «Поиск по проекту»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Поиск по проекту** по подготовленной документации.

## Документация

- Спецификация: `docs/features/project-search/spec.md` — прочитай перед началом
- План: `docs/features/project-search/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/project-search/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай spec.md, plan.md и checklist.md целиком.
2. Создай/переключись на ветку `feature/project-search` (`git checkout -b feature/project-search`).
3. Отметь в checklist.md пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** в plan.md: строго последовательно по блокам (Блок 1 → Блок 2 → Блок 3 → Блок 4).
5. После **каждой** задачи: ревью по plan.md и spec.md; убедись, что нет конфликта с другими задачами.
6. После выполнения задачи — отметь её в checklist.md (`[x]`).
7. Запусти `npm run build` после завершения Блока 3 (интеграция).
8. Коммить после каждого логического блока (после Блока 1, после Блока 2, после Блока 3+4).
9. Если что-то непонятно — спроси, не додумывай.
10. По завершении — отметь «Финализация» в checklist.md и обнови статус в README.md на `Done`.

## Архитектурные инварианты (обязательны)

- DI Container (`core/container.js`) — все компоненты через constructor injection.
- EventBus (`core/event-bus.js`) — коммуникация между компонентами.
- StateStore (`core/state-store.js`) — shared state.
- IPC_CHANNELS (`shared/ipc-channels.js`) — все имена каналов, никаких строковых литералов.
- Нет прямых обращений к `window.electronAPI` — только через `core/adapters/electron-api.js`.
- Каждый компонент с подписками имеет `destroy()`.
- Константы (числа, интервалы) — в `core/config/app-config.js`.
- CSS-цвета — через CSS-переменные (`var(--bg)` и т.д.).
