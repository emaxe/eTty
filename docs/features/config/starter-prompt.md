# Стартовый промпт для реализации фичи «Конфиг (Внешний конфиг + темы)»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Конфиг (Внешний конфиг + темы)** по подготовленной документации.

## Документация

- Спецификация: `docs/features/config/spec.md` — прочитай перед началом
- План: `docs/features/config/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/config/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай spec.md, plan.md и checklist.md целиком.
2. Создай ветку `feature/config` и переключись на неё (`git checkout -b feature/config`).
3. Отметь в checklist.md пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** и зависимостям в plan.md:
   - `#1`, `#2` — параллельно (разные файлы)
   - `#3` — строго после `#1` и `#2`
   - `#4` — параллельно с `#3`
   - `#5` — после `#3`
   - `#6`, `#7` — параллельно после `#5`
   - `#8` — после всех
5. После **каждой** задачи: ревью по plan.md и spec.md; убедись, что нет конфликта с параллельными задачами (общие файлы, противоречивая логика). Если задачу делал субагент — проверь результат перед следующим шагом.
6. После выполнения задачи — отметь её в checklist.md (`[x]`).
7. Запусти указанную для задачи проверку (`npm run dev` + ручные сценарии).
8. Коммить после каждого логического блока задач (или по правилам команды).
9. По завершении — отметь «Финализация» в checklist.md и обнови статус в README.md на `Done`.
10. Если что-то непонятно — спроси, не додумывай.

## Ключевые детали

- `userData` путь: `app.getPath('userData')` + `/eTty/`
- `config.json` — основной конфиг, структура как в текущем `settings-store.js` defaults
- `themes/*.json` — отдельные файлы тем, `id` внутри JSON, имя файла произвольное
- Валидация: критические ошибки → `dialog.showErrorBox` + fallback defaults; мелкие → `electron-log.warn()` + skip
- Вшитые темы: только `dark` и `light` в `src/renderer/themes.js`
- Остальные текущие темы → инициализация `themes/` при первом старте
