# Фича: Подсветка git diff

**Slug:** git-diff-highlight
**Jira:** не привязана
**Git-ветка:** `feature/git-diff-highlight`
**Базовая ветка для merge:** `main`
**Дата начала:** 2026-05-07
**Статус:** Done

## Краткое описание

Подсветка изменений git в файловом дереве (новые/изменённые файлы цветом) и в редакторе (индикация добавленных, изменённых и удалённых строк в области номеров строк). Функция активна только при наличии git-вкладки терминала в рабочей директории.
