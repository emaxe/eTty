# Спецификация: Настройка размера статусбара

## Контекст

В текущей версии высота статусбара и размер шрифта фиксированы (22px / 11px). Пользователи с разными предпочтениями по плотности интерфейса и разрешениями экрана нуждаются в возможности увеличить размер статусбара.

## Требования

- **REQ-1:** В настройках, категория "Оформление", добавить строку "Размер статусбара" с выпадающим списком.
- **REQ-2:** В списке три опции: `compact` (Компакт), `standard` (Стандарт), `large` (Крупный).
- **REQ-3:** Значение по умолчанию — `compact` (текущий вид, без изменений).
- **REQ-4:** При выборе `standard` высота статусбара увеличивается до 28px, шрифт элементов внутри — до 13px.
- **REQ-5:** При выборе `large` высота статусбара увеличивается до 34px, шрифт элементов внутри — до 15px.
- **REQ-6:** Padding и gap внутри статусбара остаются неизменными (только высота контейнера и шрифт).
- **REQ-7:** Настройка должна сохраняться в `config.json` и восстанавливаться при старте приложения.
- **REQ-8:** Изменение размера должно применяться мгновенно (без перезапуска).

## Ограничения

- Не затрагиваются другие панели (sidebar, editor, git panel).
- Не меняется масштаб всего приложения — только статусбар.
- Не добавляются новые IPC-каналы (используется существующий `SETTINGS_SAVE`).

## Макеты и референсы

не применимо

## Кодстайл и конвенции

- DI Container для зависимостей
- EventBus для коммуникации между компонентами
- StateStore для shared state
- `IPC_CHANNELS` для имён каналов
- Константы в `core/config/`
- `destroy()` для cleanup
- Цвета — CSS-переменные из тем
- Нет прямых обращений к `window.electronAPI`

## Переиспользуемые решения

- Паттерн `appearance.focusIndicator` в `settings-page.js` — шаблон для select-настройки
- `applyFocusIndicator` / `applyTheme` в `index.js` — шаблон для применения настроек через data-атрибуты
- `_createSelect` в `settings-page.js` — готовый UI-контрол

## Критерии приёмки

- [ ] В настройках виден пункт "Размер статусбара" в категории "Оформление"
- [ ] Переключение между compact/standard/large меняет высоту и шрифт мгновенно
- [ ] Значение сохраняется после закрытия/открытия приложения
- [ ] `npm run build` проходит без ошибок
- [ ] Нет регрессий в терминале, вкладках, файловом дереве, редакторе, git-панели

## Затронутые файлы
