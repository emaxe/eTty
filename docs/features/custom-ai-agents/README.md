## Краткое описание

Добавить поддержку произвольных (кастомных) ИИ-агентов, настраиваемых пользователем через интерфейс настроек. Каждый агент задаётся командой запуска, названием и командой отслеживания запуска. Кастомные агенты доступны в «Быстрых ответах» наравне со встроенными.
