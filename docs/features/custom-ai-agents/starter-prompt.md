# Стартовый промпт для реализации фичи «Кастомные ИИ-агенты»

Скопируй целиком и вставь в новую сессию.

---

Реализуй фичу **Кастомные ИИ-агенты** по подготовленной документации.

## Документация

- Спецификация: `docs/features/custom-ai-agents/spec.md` — прочитай перед началом
- План: `docs/features/custom-ai-agents/plan.md` — следуй порядку задач, секции «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/custom-ai-agents/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай `spec.md`, `plan.md` и `checklist.md` целиком.
2. Создай ветку `feature/custom-ai-agents` и переключись на неё (`git checkout -b feature/custom-ai-agents`).
3. Отметь в `checklist.md` пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно стратегии:
   - **Блок 1** (#1 и #2) — параллельно (subagent для #1, inline для #2)
   - **Блок 2** (#3–#8) — строго последовательно: #3 → #4 → #5 → (#6 + #7 параллельно) → #8
5. После **каждой** задачи: ревью по `plan.md` и `spec.md`; убедись, что нет конфликта с параллельными задачами. Если задачу делал subagent — проверь результат перед следующим шагом.
6. После выполнения задачи — отметь её в `checklist.md` (`[x]`).
7. Запусти указанную для задачи проверку (`npm run build` или `npm run dev`).
8. Коммить после каждого логического блока задач.
9. По завершении — отметь «Финализация» в `checklist.md` и обнови статус в `README.md` на `Done`.
10. Если что-то непонятно — спроси, не додумывай.
