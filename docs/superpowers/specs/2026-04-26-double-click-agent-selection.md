# Двойной клик для выбора ИИ-агента

Дата: 2026-04-26

## Контекст

В status-bar показаны кнопки ИИ-агентов (Claude, Codex, Copilot, Agent, OpenCode). Когда терминал занят другим приложением (busy), кнопки неактивных агентов скрываются (`display: none`). Если агент не запущен через кнопку eTty, он не определяется как «активный» (`activeAgentId === null`), и панель быстрых команд не появляется. Пользователь хочет иметь возможность **вручную назначить активного агента двойным кликом** по его кнопке, чтобы получить доступ к его быстрым командам.

## Требования

1. **Двойной клик по кнопке агента** (когда терминал busy и `activeAgentId === null`) назначает этого агента активным и показывает его быстрые команды.
2. **Одинарный клик** при busy остаётся disabled (без изменений).
3. **Авто-определение агента** через OSC 133 не изменяется — двойной клик — только fallback для случаев, когда агент не определился автоматически.
4. **Скрытие неактивных агентов** сохраняется: если activeAgentId !== null, остальные кнопки скрываются.

## Архитектура

### StatusBar (renderer)

- **Click-based double-click detection** (вместо нативного `dblclick`, т.к. порог ОС ~500ms, а JS-таймер — ~250ms).
  - Отслеживаем `lastClickTime` на каждой кнопке.
  - Если разница между кликами < 500ms — считаем double-click.
  - При double-click + busy + нет activeAgentId — вызываем `_onSelectAgent(agentId)`.
  - При одинарном клике на busy-кнопку — ничего не делаем (return early).
- **Кнопки в busy-состоянии** больше не получают атрибут `disabled` (иначе click не доходит).
  - Вместо этого используется CSS-класс `status-agent-busy`.
  - Disabled остаётся только для: а) агента, активного по кнопке; б) скрытых через Settings.

### Renderer (index.js)

- Добавить `onSelectAgent: selectAgentAsActive` в конструктор `StatusBar`.
- `selectAgentAsActive(agentId)`:
  ```js
  const tab = tabBar.getActive()
  if (!tab || !tab.isBusy) return
  tab.activeAgentId = agentId
  syncStatusBarTerminalState()
  ```
- Не отправлять команду в терминал (выбор агента — декларативный, не запускающий).

### CSS

- Добавить hover-стиль для disabled кнопок агентов, чтобы намекнуть на интерактивность:
  ```css
  .status-agent-btn:disabled:hover {
    opacity: 0.6;
    cursor: pointer;
  }
  ```

## Граничные случаи

- Пользователь двойной клик, потом агент определяется по OSC 133 — `activeAgentId` перезаписывается автоматически. Это корректное поведение: авто-определение приоритетнее.
- Переключение вкладки — `activeAgentId` хранится на уровне вкладки (`tab.activeAgentId`), поэтому состояние сохраняется.
- Закрытие агента (OSC 133 `A`) — сбрасывает `activeAgentId = null`, панель команд скрывается.
