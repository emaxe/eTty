# Процесс релиза

## CHANGELOG

При каждом новом релизе:

1. Переименовать текущий раздел `[Unreleased]` в новую версию (например `[0.1.2]`), **сохранив все записанные изменения под ней**.
2. Добавить **новый пустой** раздел `## [Unreleased]` в самый верх файла, чтобы будущие изменения записывались туда.
3. Версия увеличивается по порядку: если последняя была `0.1.2`, следующая — `0.1.3`; при значительных изменениях может меняться minor или major компонент.
4. Не удалять старые версии — история CHANGELOG накапливается сверху вниз.
